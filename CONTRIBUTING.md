# Contributing to JeiOS Mobile

New contributor? Start with the [development getting-started guide](https://github.com/auto44e/jeios/blob/main/docs/GETTING_STARTED.md),
including a plain-English conversational path with an agent.

Read AGENTS.md, README.md and docs/HANDOFF.md. Shared kernel code belongs in
auto44e/jeios; this repository owns integration and qualification. Use small
reviewable branches and PRs; do not merge or claim device qualification from
planning tests. Original contributions use Apache-2.0; preserve dependency
licenses and provenance.

## Assistance level and PR evidence

External contributors, especially those using agents: read the
[contributor guide](https://github.com/auto44e/jeios/blob/main/docs/CONTRIBUTOR_GUIDE.md). Choose as much or as little coaching as useful and
change that level at any point. Easy mode guides setup and explains development
and decisions in simple terms; hard mode retains every engineering requirement.
Run applicable local CI commands and broader change-specific tests, and include
result data using the PR template. Disclose blocked checks and environment
limitations; local and remote results are separate evidence.
